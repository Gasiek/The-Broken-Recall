1. Overview

LOWPO Mercenary Company is a stylized low-poly character and weapon pack designed for medieval, fantasy, action RPGs, and strategy games. All characters and weapons follow a consistent art style and are optimized for mobile, PC, VR, and large-scale unit battles.

The asset is URP ready, fully rigged, and prepared for animation.

TROUBLESHOOTING
⚠️ The model is PINK!

This usually means the URP material is missing or unassigned. This asset is built for URP projects.

If you are using the Built-In Render Pipeline, create a new Standard material and assign the included 512×512 texture palette manually.

⚠️ Animation doesn't work / Model is twisted!

This is commonly caused by an Avatar mismatch.

Check: The Avatar in the model's Import Settings (Rig tab) must be set to Humanoid.

Check: Ensure the Avatar assigned in the scene object's Animator component matches the target humanoid avatar setup.
