## Implementation

### Prerequisities

- Unity version 6000.6.0f1

### Scenes

The project currently contains two scenes:

- **World** — A preview of the game world containing the main elements that will be present in the final game, such as NPCs, enemies, buildings, and other game content.
- **Small Playground** — A testing scene used to develop and test individual features in isolation without the need to load the full game world.
